About this project

Needlepoint Designer is an early-stage browser application for preparing stitch-painted needlepoint charts on true canvas intersections. It is designed as a precision drafting tool rather than an automatic image-conversion program.

This first public version runs entirely in the browser. It does not require an account, and the project data is not uploaded to a server.

This release preserves the existing stocking artwork and focuses on the exact grid, intersection editing, and export workflow.
